# r2up — Cloudflare R2 Storage CLI

[English](README.md) | **Русский**

Быстрая, надежная и удобная консольная утилита для загрузки файлов и управления объектами в хранилище **Cloudflare R2** (S3-совместимое API).

> [!NOTE]
> Утилита разработана специально для сценариев **загрузки и управления**: фокус на высокой скорости передачи, отображении прогресса в реальном времени, сохранении структуры каталогов и понятных отчетах без лишних накладных расходов.

---

## 🚀 Возможности

- ⚡ **Быстрая загрузка**: использует `boto3` с автоматической поддержкой multipart upload для больших файлов.
- 📊 **Наглядный интерфейс**: цветной прогресс-бар в реальном времени (`rich`) со скоростью (MB/s), оставшимся временем и процентами.
- 📁 **Рекурсивная загрузка папок**: флаг `-r` / `--recursive` с сохранением структуры каталогов.
- 🎯 **Управление ключами**: целевой префикс (`--prefix`) или точный ключ (`--key`).
- 🔍 **Режим предпросмотра**: флаг `--dry-run` для проверки файлов и путей перед отправкой.
- 🛡️ **Защита от перезаписи**: флаг `--no-clobber` пропускает уже существующие объекты.
- 📂 **Создание папок**: создание маркеров директорий через `r2up --mkdir` (или `r2up mkdir`).
- 📋 **Просмотр хранилища**: табличный вывод файлов и папок через `r2up --ls` (или `r2up ls`).
- 🧹 **Очистка незавершенных загрузок**: отмена зависших частей через `r2up --abort` (или `r2up abort`).
- ⚙️ **Умная нормализация**: авто-очистка `R2_ENDPOINT_URL` от случайно указанных путей и бакетов.

## 📦 Установка

### 1. Рекомендуется: Глобальная установка через `pipx`
[pipx](https://pypa.github.io/pipx/) изолирует зависимости и делает команду `r2up` доступной глобально **из любого терминала и любой папки**:

```bash
# Установка напрямую из GitHub
pipx install git+https://github.com/artykovv/r2up.git
```

Или из скачанной локальной папки:
```bash
git clone https://github.com/artykovv/r2up.git
cd r2up
pipx install .
```

*(Также поддерживается стандартный `pip install .`)*

### 2. Для разработчиков (Poetry)
```bash
git clone https://github.com/artykovv/r2up.git
cd r2up
poetry install
poetry run r2up --help
```

## 🛠️ Настройка окружения (`.env`)

`r2up` ищет конфигурацию в следующем порядке:

1. **Глобальный конфиг пользователя (Рекомендуется для глобального CLI)**:
   Разместите файл `.env` в `~/.config/r2up/.env` (или `~/.r2up.env`), чтобы команда `r2up` работала из любых каталогов:
   ```bash
   mkdir -p ~/.config/r2up
   cat << 'EOF' > ~/.config/r2up/.env
   R2_ENDPOINT_URL="https://<ACCOUNT_ID>.r2.cloudflarestorage.com"
   R2_ACCESS_KEY_ID="your_access_key_id"
   R2_SECRET_ACCESS_KEY="your_secret_access_key"
   R2_BUCKET_NAME="your_bucket_name"
   EOF
   ```

2. **Текущий каталог**:
   Файл `.env` в текущей рабочей папке терминала.

3. **Переменные окружения системы**:
   Экспортированные переменные оболочки (`export R2_ACCESS_KEY_ID=...`).

## 💻 Использование

Утилита `r2up` поддерживает как **флаги** (`r2up --upload`, `r2up --mkdir`, `r2up --ls`, `r2up --abort`), так и **подкоманды** (`r2up upload`, `r2up mkdir`, `r2up ls`, `r2up abort`).

### 1. Загрузка одного файла
```bash
# Прямая передача (режим по умолчанию)
r2up photo.jpg

# Или явный флаг
r2up --upload photo.jpg

# Или подкоманда
r2up upload photo.jpg
```

С указанием папки-префикса в бакете:
```bash
r2up photo.jpg --prefix uploads/2026
```

С явным именем ключа объекта:
```bash
r2up photo.jpg --key avatars/admin.jpg
```

### 2. Загрузка нескольких файлов
```bash
r2up file1.txt file2.pdf archive.zip
```

### 3. Рекурсивная загрузка папки
Используйте флаг `-r` (или `--recursive`) и `--prefix` (или `-p`):

```bash
# Вариант А: Папка my_folder будет создана внутри целевого префикса
# Результат в R2: live/2026/my_folder/file.txt
r2up -r ./my_folder/ --prefix live/2026

# Вариант Б: Только содержимое папки загрузится напрямую в префикс
# Результат в R2: live/2026/file.txt
r2up -r ./my_folder/ --prefix live/2026 --content-only

# Вариант В: Если вы уже находитесь внутри этой папки (используйте точку .)
# Результат в R2: live/2026/file.txt
r2up -r . --prefix live/2026
```

### 4. Предпросмотр без загрузки (Dry Run)
```bash
r2up -r ./my_folder/ --dry-run
```

### 5. Пропуск уже существующих файлов (не перезаписывать)
```bash
r2up -r ./my_folder/ --no-clobber
```

---

### 6. Создание папок в R2 (`--mkdir`)
Создание маркеров директорий (ключей, заканчивающихся на `/`) в бакете:

```bash
# Через флаг
r2up --mkdir photos

# Или через подкоманду
r2up mkdir photos

# Создать несколько папок сразу
r2up --mkdir documents archive logs

# Создать вложенную структуру папок
r2up --mkdir 2026/backups/database

# Внутри родительской папки (префикса)
r2up --mkdir albums --prefix user_101

# Предпросмотр без создания
r2up --mkdir new_folder --dry-run
```

---

### 7. Просмотр списка папок и файлов (`--ls`)
Табличный вывод содержимого хранилища:

```bash
# В корне бакета
r2up --ls
# (или: r2up ls)

# Внутри конкретной папки
r2up --ls live
# (или: r2up ls live)

# Только папки (скрыть файлы)
r2up --ls live -d

# Рекурсивный вывод всех вложенных файлов и папок
r2up --ls -r
```

---

### 8. Очистка прерванных загрузок (`--abort`)
Если передача большого файла была прервана (`Ctrl+C`), Cloudflare R2 может сохранять незаконченную multipart-загрузку. Чтобы очистить такие зависшие части:

```bash
# Отменить все незавершенные multipart-загрузки
r2up --abort
# (или: r2up abort)
```

---

### 9. Справка по всем опциям
```bash
r2up --help
r2up mkdir --help
r2up ls --help
r2up abort --help
```
